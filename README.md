# Open Estimate Spec

An open specification for exchanging construction estimates between tools.

The goal is to represent an estimate without tying it to one application's database or file format. The specification will define common
concepts such as estimate structure, quantities, units, costs, prices, and supporting references.

## Status

This project is at the beginning. No schema or file format has been adopted yet.

Initial work will define the scope and terminology, then develop examples and a versioned schema. Compatibility and extension rules will be documented alongside the schema.
